# Pre-entrega: Adquisición y Normalización con Pandas

Este proyecto simula un pipeline de ingeniería y análisis de datos en Python, integrando registros de transacciones provenientes de un archivo CSV con un maestro de productos almacenado en un archivo Excel, aplicando técnicas de limpieza, normalización y exportación en formato optimizado.

## Librerías Necesarias
Para ejecutar este proyecto correctamente, asegurate de tener instaladas las siguientes librerías:

```bash
pip install pandas openpyxl pyarrow
